# Teacher-refined air traffic QA (August 2026, train days)

19,542 question-answer pairs about multi-aircraft traffic scenes in the New York terminal area
(JFK, LGA, EWR; 60 NM radius). Questions and answers were generated by rules from ADS-B tracks,
then rewritten and explained by GPT-4.1-mini, and checked by code (answer value unchanged, no
aircraft that is not in the scene, no numbers taken from the future).

## Files
- `examples.md`: three full records (situation, risk, scene overview) in both formats, easy to read.
- `raw.jsonl`: the user message holds the last 2 minutes of every aircraft in the scene as a table
  (21 points every 6 s: t [s], x, y [NM], alt [ft]).
- `summary.jsonl`: the user message holds one summary sentence per aircraft instead of the table.

Both files hold the same QA pairs in the same order. One line per QA, in the conversational
prompt-completion format used by Hugging Face TRL:
- `prompt`: `[system, user]` messages. The user message holds the scene and the question.
- `completion`: `[assistant]` message, the target answer. With prompt-completion data, TRL's
  `SFTTrainer` computes the loss on the completion only (`completion_only_loss`, on by default),
  so the model is not trained to reproduce the long coordinate tables.
- `id`, `scene_id`, `type` (question type), `bucket` (situation 5,895, risk 3,717, single 3,052, scene 2,941, pair 2,931, probe 1,006),
  `future` (true if the answer is about the next 2 minutes).
- `value`: structured ground truth for scoring (class, aircraft number, number, list).
- `question_rule`, `answer_rule`: the original rule-based question and answer.

## Notes
- Raw-format prompts are long (often 8-10k tokens, more in busy scenes); use a max length of about 16k.
- Coordinates: x east, y north, NM from the centroid of the three airports. The system message
  gives the airport and runway coordinates in the same frame.
- Aircraft are named AC1..ACN in a random order in every scene.
- These come from the 24 training days of August 2026. Validation (Aug 10, 19, 28) and test
  (Aug 4, 13, 22, 30) days are separate and not included here.
